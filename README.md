# 定时关机 / Windows-shutdown-timer

Windows定时关机工具。v2.1.11提供固定布局的原生单EXE版本。

下载或取出`ShutdownTimer.exe`后可直接运行。界面、托盘、提醒均在这个EXE中，说明和源码不是运行依赖。Windows10/11使用系统自带的.NET Framework4.x。

## 固定窗口

本版依据已确认的1080p紧凑界面设计，客户端尺寸为294×425；Windows标准外框约310×465，外框随系统主题略有不同。窗口不可拖拽改变大小，不再按屏幕分辨率压缩字号或改变布局。Windows显示缩放只对窗口与内容整体同比缩放。

在相同缩放下，1080p、2K、4K的窗口尺寸与内部布局相同；在不同缩放下，窗口和控件保持同一比例。保持微软雅黑、按钮和输入数字粗体、深蓝色数字、左右等宽操作区、固定底部间距与完整“预计关机时间”。

## 功能与使用

- 快捷设置30分钟、1小时、1.5小时、2小时、3小时，或输入自定义整数分钟。
- 显示倒计时和预计关机时间，成功设置约2秒后隐藏到托盘。预计关机时间使用设定计划时保存的固定时间，倒计时单独逐秒变化；重新设置计划后更新预计关机时间。
- 双击托盘图标或再次运行EXE恢复界面。
- 保留关机前提醒和取消计划；有计划时退出需确认，选择继续则保留计划并隐藏。退出确认弹窗仅保留按钮上方的保存文件说明，说明去掉末尾句号并按窗口宽度横向居中，客户端设计高度为168个设计像素。
- 开机自启动默认关闭；主界面和托盘菜单均可切换，登录后仅驻留托盘，不自动设置关机时间。
- 首次手动运行时，自动在当前用户桌面创建“定时关机”快捷方式；以后运行新版时，按需更新已有的本程序快捷方式。可从托盘菜单“创建／更新桌面快捷方式”手动修复。登录自启动不创建或更新桌面快捷方式。
- 状态框内的可见文字作为一组上下居中，状态框及其他功能区位置固定。快捷时长按钮恢复原版蓝底白字悬停配色；托盘与取消按钮使用各自的原版交互配色。

更新前先退出旧版托盘，再运行新版；旧版有计划时确认退出会取消计划，请在新版重新设置。自启动和快捷方式直接指向当前EXE，设置后请保留该文件的位置。

## 实现与误报处理

界面和状态读写由C#直接完成。EXE只嵌入图标，不释放脚本或辅助EXE，不调用HTA、mshta、WScript、cmd或PowerShell，不联网下载或执行代码。实际关机调用Windows系统目录下的shutdown.exe，参数仅由已验证的分钟数产生。

采用普通原生程序结构以减少可能导致误报的行为；尚未取得数字签名或完成360实机及官方误报复核，不能保证安全软件都解除告警。如仍报警，可通过[360官方入口](https://open.soft.360.cn/report.php)提交EXE、截图、说明和SHA256校验值。

到点后Windows可能关闭仍在运行的程序，请提前保存文件。

## 从源码编译

在Windows PowerShell中执行：

```powershell
.\build.ps1 -Verify
```

脚本生成EXE、说明、校验值、ZIP及五档缩放预览；测试使用模拟关机执行器和模拟自启动存储。

详细结果见[验证说明](docs/verification.md)。GitHub Actions 在 Windows 上编译并验证，通过后发布版本。
