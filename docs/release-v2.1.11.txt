定时关机 v2.1.11 · 原生单文件版

本版汇总本次对话确认的界面与功能修正。

主要变化
- 使用 C# 原生界面，单个 EXE 即可运行，界面、托盘和提醒均集成在程序中。
- 主窗口采用 294×425 的固定设计尺寸；同一 Windows 显示缩放下，1080p、2K、4K 保持相同尺寸与布局。显示缩放仅对窗口和内容整体同比缩放。
- 保持微软雅黑、清晰的按钮与输入数字、对齐的操作区、居中的倒计时文字和调整后的功能区及底部间距。
- 恢复按钮悬停配色与完整文字显示，默认 30 分钟按钮不凸显。
- 首次手动运行自动创建当前用户桌面的“定时关机”快捷方式；运行新版时按需更新本程序已有快捷方式。
- 修复“预计关机时间”秒数跳动：预计时间保持设定时保存的时间，倒计时逐秒更新。
- 开机自启动可选，默认关闭；启用后登录仅驻留托盘，不自动安排关机。
- 退出确认窗口缩减为 360×168，只保留按钮上方的保存文件说明；说明横向居中、去掉末尾句号，字号 12 个设计像素。
- “开机自启动”和退出弹窗说明均采用标准字重（Regular）。

下载与更新
1. 下载 ShutdownTimer.exe，或解压 ShutdownTimer-v2.1.11.zip 后取出 EXE。
2. 先退出旧版托盘程序，再运行新版。旧版有活动计划时退出会取消计划，请在新版重新设置。
3. 将 EXE 放到准备长期保留的文件夹后再运行；桌面快捷方式和开机自启动直接指向该 EXE，请保留文件位置。
4. Windows 10/11 使用系统自带 .NET Framework 4.x。说明和校验文件不是运行依赖。

验证
已通过本地构建及 963 项模拟检查，检查主界面和五档退出弹窗缩放预览。发布流程另在 GitHub Windows 环境执行 .\build.ps1 -Verify、快捷方式检查及内嵌资源检查；结果见仓库 Actions。
本地模拟未执行真实关机、登录自启动或安全软件扫描。程序没有数字签名；本版不释放或运行 HTA、脚本及辅助 EXE。请在关机前保存文件。
