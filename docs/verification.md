# 验证说明

v1.0.0 发布文件使用已检查的单文件程序。模拟检查包括：

- 56 项界面逻辑检查：输入验证、设置与取消计划、命令失败、存储失败、延迟隐藏、退出等。
- 36 项原生模型检查：倒计时、提醒阈值、锁、取消、退出确认策略等。
- 33 项单文件检查：内置资源、安装、修复、中文与空格路径、移动 EXE、快捷方式、并发安装、测试模式隔离等。
- 4 项托盘进程检查：拒绝退出后保留倒计时、确认后取消模拟计划、无计划直接退出等。

关机和取消命令在检查中均被模拟；未执行真实关机终点。测试安装文件仅写入指定的测试目录，不改动实际桌面或真实关机计划。

重新编译后，可执行：

```powershell
node .\tests\check_ui.cjs
.\dist\定时关机.exe --selftest .\build\native-checks.txt
.\tests\check_lifecycle.ps1
```

`check_bundle.cs` 是独立的安装资源检查程序，需用 C# 编译器编译。运行时传入 EXE 路径和一个新的测试目录：

```powershell
.\tests\check_bundle.exe .\dist\定时关机.exe .\build\bundle-qa
```

`--selftest` 和 `--demo` 使用模拟模式；不会安装到真实用户目录或执行系统关机。
